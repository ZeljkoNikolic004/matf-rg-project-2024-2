# Car crash scene

124/2023 - Zeljko Nikolic  
This project features a car crash scene with camera controls, adjustable directional and point 
lighting, and an interactive event chain with GUI controls for manipulating the scene.

## Controls

{W} -> Move camera forward
{S} -> Move camera backward
{A} -> Move camera left
{D} -> Move camera right
{MOUSE} -> Look around / rotate camera
{F1} -> Toggle cursor
{F2} -> Toggle lighting GUI
{SPACE} -> Start event chain
{R} -> Reset event chain
{ESC} -> Exit application
